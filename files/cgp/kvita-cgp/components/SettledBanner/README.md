# SettledBanner

Temen panel s stanjem »Kvita ✓«, ko so vse obveznosti obdobja potrjene – nagrada, zaradi katere se aplikacija tako imenuje.

- Ozadje `panel` z okrasno mrežo 24 px, znak v `signal`, naslov `h2`, opis v `ink-on-panel-muted`.
- Prikaži samo, ko je res vse `confirmed`; nikoli kot okras ali pri delno plačanem mesecu.
- Besedilo pove, kaj je poravnano in kdaj je naslednji rok.
- Ima `role="status"`, da ga bralniki zaslona preberejo.
